mend applies AI-written edits to a tree of text files: unified diffs (often with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and text-editor tool calls as JSON. It finds the lines each edit names at the first of three matching tiers, and writes every change or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
